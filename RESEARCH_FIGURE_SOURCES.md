# Published research figures

Three original graphical abstracts are reproduced unchanged in Yu Sakurai’s own research portfolio. The local JPEG files are the publisher-provided high-resolution originals, without cropping, relabeling, image generation or recompression. CSS scales the complete images proportionally; an enlargement link opens each original.

Source pages, image links and reuse terms were checked on 25 September 2026. Figure attribution is visible on the page, with the full citation and reuse information in a disclosure. The static HTML contains the same figures and citations as the interactive version.
